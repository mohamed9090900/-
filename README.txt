دراسة الجدوى V5 — نسخة مبسطة.

التعديلات:
- قسم البضاعة مخصص لتكلفة الشراء ورأس المال فقط، بدون سعر بيع أو ربح لكل صنف.
- إزالة المصروف السنوي من الإدخال والعرض.
- استبدال جزء صافي الربح بحساب نقطة التعادل الشهرية.
- نقطة التعادل تعتمد على المصروفات الشهرية + متوسط هامش مجمل الربح الذي يُدخل مرة واحدة من إعدادات الدراسة.
- رأس المال المطلوب = تكاليف التأسيس + احتياطي التشغيل + احتياطي الطوارئ.
- البيانات القديمة محفوظة، وأي بند قديم مصنف سنويًا يُعامل كتأسيس بعد التحديث.
